# data/synthetic — dataset outputs

Generated by `scripts/generate_synthetic_ismi_dataset.py`. Two files per run:

- `<basename>.jsonl` — one dataset item per line (the canonical dataset).
- `<basename>.pretty.json` — the same items as one indented array (for reading).

`--mock` runs write `<basename>.mock.jsonl` / `.mock.pretty.json` (offline stub,
`model="mock"`). Audits write `<basename>.audit.jsonl` (one audit record per line).

## ⚠️ Judge-input contract

The blinded ISMI/RSES judge must receive **only** the `visible_dialogue` field.
Everything else (`hidden_ground_truth`, `condition`, `author_evidence`,
`prompt_version`, `seed`, `model`, …) is generation/analysis metadata and would
leak the answer. Extract like:

```python
import json
for line in open("ismi_reducing_v2.jsonl"):
    item = json.loads(line)
    judge_input = {"sample_id": item["sample_id"], "visible_dialogue": item["visible_dialogue"]}
    # feed ONLY judge_input to the judge
```
